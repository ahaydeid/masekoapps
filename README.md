# masekoapps

Aplikasi web mobile-first pemantauan stok gudang dan daftar harga produk terintegrasi Google Sheets & Google Apps Script.

## Menjalankan Lokal

1. Salin `.env.example` menjadi `.env` lalu isi `VITE_GAS_API_URL` dengan URL Web App Google Apps Script.
2. Instal dependensi dan jalankan server pengembangan:

```bash
npm install
npm run dev
```
